**Laundry Tracker**
A Smart Laundry Management System for Dorm Students

**About the App**
Laundry Trackeris a web application designed for dorm students to easily monitor and manage their laundry. It helps students track their laundry loads, drop-off dates, and pickup schedules. The application provides a simple and organized way to check the current status of their laundry without needing to log in or create an account.

Features
- **Add Laundry Load** – Users can enter their laundry details and create a new laundry record.
- **Laundry Code** – Each laundry load has a unique tracking code.
- **Track Laundry Status** – Monitor whether laundry is pending, washing, drying, ready for pickup, or completed.
- **Drop-off Tracking** – Record the date and time when laundry is dropped off.
- **Pickup Tracking** – Monitor when laundry is ready and when it has been picked up.
- **Search Laundry** – Find laundry records using the assigned laundry code.

Laundry Tracker can be used on both a **cellphone and a laptop**. You don't need to install a separate app because you can access it through a web browser and add it to your home screen for easier access.

### For Cellphones (Android and Apple)

1. Open the Laundry Tracker website using **Google Chrome** or **Safari**.
2. Wait for the website to finish loading.
3. Tap the **three-dot menu (⋮)** in the upper-right corner of Chrome.
4. Select **"Add to Home screen"** or **"Install app"** if available.
5. Tap **Add** or **Install** to confirm.
6. The Laundry Tracker icon will appear on your home screen.
7. Tap the icon whenever you want to open and use the application.

### For Laptops and Computers

1. Open **Google Chrome**, Microsoft Edge, or another modern web browser.
2. Open the Laundry Tracker website.
3. If available, click the **Install icon** in the address bar or open the browser menu.
4. Select **"Install Laundry Tracker"** or **"Install app."**
5. Confirm the installation.
6. Laundry Tracker will open in its own window and can be accessed anytime from your desktop or applications menu.

###  How to Run the Project (For Developers)

If you have the project files and want to run the application locally:

**Requirements:**
- Laptop or computer
- Visual Studio Code
- Node.js (if the project uses it)

**Steps:**

1. Download or clone the Laundry Tracker project.
2. Extract the ZIP file if necessary.
3. Open the project folder in Visual Studio Code.
4. Open the terminal inside VS Code.
5. Type the following command to install the required files:

   `npm install`

6. Start the application by typing:

   `npm run dev`

7. Open the local link shown in the terminal, usually `http://localhost:5173`.
8. The Laundry Tracker is now ready to use!

**Note:** If the project is built using only HTML, CSS, and JavaScript, you can simply open the `index.html` file in your browser, or use the Live Server extension in Visual Studio Code.
