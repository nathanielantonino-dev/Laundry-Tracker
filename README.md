**Laundry Tracker**
A Smart Laundry Management System for Dorm Students

**About the App**
Laundry Trackeris a web application designed for dorm students to easily monitor and manage their laundry. It helps students track their laundry loads, drop-off dates, and pickup schedules. The application provides a simple and organized way to check the current status of their laundry without needing to log in or create an account.

Features
- **Add Laundry Load** – Users can enter their laundry details and create a new laundry record.
- **Laundry Code** – Each laundry load has a unique tracking code.
- **Track Laundry Status** – Monitor whether laundry is pending, washing, drying, ready for pickup, or completed.
- **Drop-off Tracking** – Record the date and time when laundry is dropped off.
- **Pickup Tracking** – Monitor when laundry is ready and when it has been picked up.
- **Search Laundry** – Find laundry records using the assigned laundry code.
- **Dashboard** – View laundry statistics and track active loads.
- **No Login Required** – Users can access the application without creating an account.
- **User-Friendly Interface** – Simple, clean, and responsive design for easy navigation.

**How to Install and Run**

Follow these steps to install and run the Laundry Tracker application on your computer.

**Prerequisites**
- A computer or laptop
- A modern web browser (Google Chrome, Microsoft Edge, or Firefox)
- Visual Studio Code (recommended)
- Node.js and npm (if the project uses a Node.js development server)

**Installation**

1. Download or clone the Laundry Tracker project.
2. Extract the project folder if it is downloaded as a ZIP file.
3. Open the project folder in Visual Studio Code.
4. Open the terminal in Visual Studio Code.
5. Install the required dependencies if the project has a `package.json` file:

    bash
   npm install
   

**Running the Application**

If the project uses Vite, run:

bash
npm run dev

6. Open the local URL displayed in the terminal, usually `http://localhost:5173`.
7. The Laundry Tracker application is now ready to use!

**Note:** If the project is a simple HTML, CSS, and JavaScript application without Node.js, open the `index.html` file directly in your web browser or use the Live Server extension in Visual Studio Code.
